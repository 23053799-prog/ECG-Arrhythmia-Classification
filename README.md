# ECG Arrhythmia Classification using Machine Learning

This repository contains my research project on ECG Arrhythmia Classification using the MIT-BIH Arrhythmia Database.

## Project Workflow

- ECG Signal Processing
- Heartbeat Extraction
- Exploratory Data Analysis (EDA)
- Data Preprocessing
- Feature Engineering
- Feature Selection
- Class Balancing
- Machine Learning Model Comparison
- Hyperparameter Optimization
- SHAP Explainability
- Missing Value Robustness Analysis
