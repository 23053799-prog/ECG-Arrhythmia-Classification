# ECG Arrhythmia Classification

This repository contains my research project on ECG Arrhythmia Classification using the MIT-BIH Arrhythmia Database.

## Project Workflow

- ECG Signal Processing
- Heartbeat Extraction
- Exploratory Data Analysis (EDA)
- Data Preprocessing
- Feature Engineering
- Feature Selection
- Machine Learning Models
- Hyperparameter Optimization
- SHAP Explainability
- Missing Value Robustness Analysis

Dataset: MIT-BIH Arrhythmia Database
Platform: Kaggle
Language: Python
